# VORG Course 1 - Luxury Fashion Compositing Taste

## Decision supported

Build taste and compositing judgment through exact, private master studies of real official Jacquemus and Rhode images, then transfer the learned principles into original VORG work.

This course does not use AI-generated practice targets. Jacquemus and Rhode are studied separately. The final capstone must use VORG-owned or properly licensed photography, products, garments, and talent.

## Start here

1. Open `presentation/VORG_Course_1_Luxury_Compositing_Taste.pdf`.
2. Print or annotate `workbook/VORG_Course_1_Workbook.pdf`.
3. Begin with `references/jacquemus/studies/J01/` and Week 1.
4. Record progress in `dashboard/VORG_Course_1_Progress_Tracker.csv`.
5. Use `youtube_curriculum/verified_youtube_lessons.csv` only when a weekly exercise calls for software instruction.

## Package contents

- 85-slide presentation PDF.
- 53-page workbook PDF.
- 40 reduced-resolution official references: 20 Jacquemus and 20 Rhode.
- Six master studies: J01-J03 and R01-R03.
- Four mechanical reductions per study: grayscale, blur read, value groups, and silhouette.
- Eight weekly exercise briefs.
- Photoshop, Blender, DaVinci Resolve, and on-set templates.
- 13 direct YouTube lessons verified on 2026-07-10.
- Source manifests with official page URLs, access dates, categories, reasons, and usage notes.

## Eight-week order

1. Taste, hierarchy, and source analysis.
2. Photography and RAW source control.
3. Premium shine and reflection design.
4. Blender camera, materials, and transparent passes.
5. Photoshop integration and texture-preserving retouching.
6. Color management and campaign consistency.
7. DaVinci Resolve 21, restrained motion, and system QA.
8. Original six-image VORG capstone.

- Blender 5.1 stable.
- Adobe Photoshop 27.8.

Photoshop remains the main detailed still-compositing and retouching tool in this course. Resolve is used for photo grading where useful, campaign consistency, motion, shot matching, and delivery.

## Editable-source note

The presentation and workbook are generated from `tools/build_course_pdfs.py`, so the content and layout source is editable. An editable PPTX is not included because the required private `@oai/artifact-tool` presentation runtime was unavailable in this environment. The PDF deliverables were rendered and visually checked.

Rebuild the PDFs from the repository root with:

```powershell
python VORG_Course_1/tools/build_course_pdfs.py
```

Rebuild the study reductions with:

```powershell
python VORG_Course_1/tools/prepare_master_studies.py
```
