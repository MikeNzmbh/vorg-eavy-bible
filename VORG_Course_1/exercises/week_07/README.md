# Week 7 - Resolve, motion restraint, and system QA

Decision: use motion only when it improves the campaign idea.

## Work

1. Bring one approved still system into DaVinci Resolve 21.
2. Create a six-second teaser with one controlled motion event.
3. Check shot matching, scopes, grain behavior, highlight roll-off, and mobile crop.
4. Audit every frame for face, garment, label, color, and geometry truth.
5. Revise every frame scoring below 75.

## Deliverable

`Week_07_Motion_Consistency_Test.mp4`, still frame strip, node tree, and QA scorecard.

Pass: motion does not expose compositing seams or weaken product recognition.
