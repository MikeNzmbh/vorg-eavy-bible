# Week 4 - Blender for fashion compositing

Decision: build only the CGI elements the photographed plate actually needs.

## Work

1. Match one real camera using the Week 2 metadata and plate lines.
2. Work at real-world scale with measured bevels.
3. Build red lacquer, chrome, stone, glass, and wet-floor material tests.
4. Design reflections with cards and environment lighting.
5. Render transparent beauty, object mask, and shadow information.

## Deliverable

Working `.blend` scene, reusable material library, transparent renders, and one first-pass composite.

Pass: camera and lighting relationships hold at final delivery size. Revise any material that depends on a label instead of visible evidence.
