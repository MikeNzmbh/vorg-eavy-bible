# Photoshop layer-stack template

Use top to bottom. Keep major decisions reversible and name every layer by job.

1. `OUTPUT_CHECKS`
   - final-size proof
   - gamut/soft-proof check
   - sharpen for output
   - grain at delivery resolution
2. `CAMPAIGN_LOOK`
   - global look
   - protected skin/product masks
   - black and white level control
3. `INTEGRATION`
   - atmospheric depth
   - edge contamination and light wrap
   - local color interaction
   - defocus or motion blur by plane
4. `CGI_OR_INSERTED_OBJECT`
   - object smart object
   - material corrections
   - reflection/highlight corrections
   - object mask
5. `SHADOW_SYSTEM`
   - contact shadow
   - cast shadow
   - ambient occlusion cue
   - reflected-light lift
6. `REAL_PHOTO_TRUTH`
   - texture-preserving cleanup
   - garment/product truth corrections
   - skin corrections
7. `SOURCE_PLATE`
   - RAW-developed plate as smart object
   - clean plate
   - references and notes

Required checks: color, grayscale, 100 percent, final output size, flipped canvas, and five-minute break review.
