# Brand

## Public Idea

A home for Originals.

## Internal Operating Idea

The Firm: access, polish, ambition, discipline.

## Direction

VORG-EAVY should feel selective, controlled, and culturally charged. The brand should combine luxury restraint with youth access pressure.

## Palette

- Void Black: `#0B0B0C`
- Stark White: `#F5F3EE`
- Walnut: `#6B4C35`
- Deep Walnut: `#4B3323`
- Signature Orange: `#F56A1C`

## Rule

Do not make the brand noisy. Let scarcity, material, fit, photography, and controlled access carry the weight.
