# Pop-Up Blueprint

## Concept

Two modes in one room:

- daytime: sparse, hospitality-led, premium
- nighttime: access-led, social, content-heavy

## Layout

```text
ENTRY / RSVP DESK
RSVP list / guest check / bag drop

HERO DISPLAY
one jacket pedestal

COFFEE / WATER BAR
licensed partner

FITTING + MIRROR
2 rails max, staff-assisted

CHECKOUT / PICKUP
POS, packing, stock

PHOTO BOOTH / FLASH WALL
opt-in image capture
```

## Version-One Rules

- No alcohol.
- No haze.
- No open flames.
- No uncontrolled crowd stunts.
- One queue only.
- Security lead can stop entry.
- Keep stock controlled.
- Capture photo consent.

## Staffing

- Event lead
- Door / RSVP lead
- Security
- Fitting support
- Coffee partner staff
- Checkout / stock runner
- Photographer
- Runner

## Compliance Reminder

Use an indoor venue already approved for retail or assembly use. Confirm insurance, food service, music licensing, capacity, and any municipal event requirements before deposits.
