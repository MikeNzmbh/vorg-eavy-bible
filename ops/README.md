# Operations

## Pop-Up Principles

- Use an indoor venue already approved for retail or assembly use.
- No alcohol for version one.
- No open flames, haze, or uncontrolled crowd mechanics.
- Use a licensed coffee partner if serving coffee.
- Keep door, stock, checkout, and photo consent controlled.

## Staffing

- Event lead
- Door / RSVP lead
- Security
- Stylist or fitting support
- Checkout / stock runner
- Photographer
- Runner
