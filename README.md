# VORG-EAVY Bible

This repo is the internal source of truth for VORG-EAVY.

Use it for the brand thesis, launch strategy, product system, financial model, pop-up operating playbook, research notes, and founder decisions.

## Structure

- `AGENTS.md` - agent instructions and truth boundaries
- `docs/` - master brief, handoff, decision log, adjacent app context
- `strategy/` - market thesis, operating model, launch gates, strategic decisions
- `brand/` - identity, voice, palette, references, packaging, worldbuilding
- `product/` - SKU specs, materials, tech pack notes, sourcing, quality rules
- `launch/` - campaigns, scripts, shot lists, pop-up plan, distribution calendar
- `ops/` - vendors, run-of-show, compliance, logistics, checklists
- `finance/` - unit economics, budgets, P&L assumptions, cash gates
- `research/` - source notes, competitor references, models, citations
- `site/` - public Drop 001 site prototype and team-facing Drop OS dashboard
- `VORG_Course_1/` - real-image luxury compositing course, workbook, references, exercises, and source manifests

## Working Rule

If something changes the company, product, or launch plan, it belongs here.
