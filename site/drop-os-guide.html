Drop OS walkthrough

Screenshot guide for the whole desk — every lane, every move. Drop OS is VORG-EAVY's internal drop desk: one collection, one city wedge, bag checks before bulk spend. If you're new, do the tour on first open, then use this page when you need the receipts.

0. First open — orientation tour

First time on this device? You get a 4-step tour. It explains bag check (GO / TEST / FIX IT / HOLD), the 10 gates, picking your lane, and that data lives in this browser until you export.

  1. 1Open drop-os.html in Chrome, Edge, or Safari.
  2. 2Read each tour card — 4 steps total.
  3. 3Land on Drop desk when done.
Heat → Concept → Sample → Campaign Proof → Production → Campaign Build → Online Drop → Pop-Up → VORG After → Debrief
Drop 001 launches open on Shopify — no password gate. Scarcity = units + timing + the room.

1. Drop desk — home base (2 min every session)

Start here every time. Read the bag check, peep the bag lock banner, update your gate, stack this week's run.

Playbook strip

The gradient bar under the header changes per lane. On the desk it tells you: read bag check → bag lock → tap your gate → stack moves.

Update a milestone (gate workbench)

  1. Scroll to Drop milestones timeline.
  2. Tap your gate (e.g. Campaign Proof).
  3. Set Status, Gate result (test / revise / approve / kill), score, and Proof link.

Add a move to this week's run

  1. In This week's run, type what ships (e.g. "Book fit relay shoot").
  2. Pick the gate from the dropdown.
  3. Hit +. Tap ○ to mark done.

Proof links

The desk now pulls every gate's proof link into one receipts panel. If a tech pack, quote, Drive folder, campaign clip, or Loom matters, paste it into the gate workbench so the bag check has real proof attached.

Readiness model (optional deep dive)

Expand Readiness model to see proof check, milestone pace, market heat, content proof, risk tax, and stress sliders.

2. Heat radar — log what's pulling

DMs, saves, waitlist joins, fit questions, creator buzz — log it while it's hot.

  1. Sidebar → Heat radar.
  2. Describe the pull (e.g. "Jacket fit DMs after founder table").
  3. Add source (IG DMs, TikTok, pop-up…).
  4. Pick city. Set heat 0–100 (vibes, not forecast).
  5. Hit Log heat.

3. SKU room — samples & hero pics

Three SKUs for Drop 001. Upload reference shots (browser-local). Link tech packs in the gate proof field on the desk.

  1. Sidebar → SKU room.
  2. Tap jacket, top, or cap in the nav.
  3. Hit Upload photo — picks from your device, compresses in-browser.
  4. Use Edit SKU to fix units, price, or risk fields after the line changes.
  5. Paste final asset links in the milestone proof field on Drop desk.
Uploads are desk reference only — not final Shopify assets until e-comm photography is locked.

4. Campaign proof — content before bulk

Approve tactics only when the proof mechanic is real and consented. No bulk until Campaign Proof clears.

  1. Sidebar → Campaign.
  2. Read the campaign gate banner.
  3. Approve tactics (Founder Table, Firm Sightings, etc.) only when proof exists.

5. Factory gate — quotes & PP sample

Vendor quotes, MOQ, landed COGS, PP sample — checklist before any bulk PO. Tap cards as proof lands; progress saves in this browser and snapshot.

6. Online drop — Shopify goes live

Open storefront, sizing, checkout, sold-out UX, next-city waitlist. No password gate on Drop 001.

7. Pop-up & VORG After — the room and the night

Toggle between day-room pop-up checklist and VORG After night party checklist.

8. Next city — where the line travels

Scores blend all logged heat per city. Ottawa/Gatineau is the wedge — others are expansion reads only.

9. Debrief — what the drop proved

Run after the January 2027 business-quality gate. Log revenue, sell-through, margin, content, and city pull — then pick repeat, revise, or scale.

  1. Sidebar → Debrief.
  2. Fill units sold, margin achieved, and campaign highlight.
  3. Pick a verdict and save — exports in snapshot + Supabase sync.

10. Handoff — backup & squad sync

Export for laptops without sync. With Supabase configured, the squad row updates automatically — still snapshot daily for SKU photos.

Copy or download snapshot (daily backup)

  1. Handoff → Copy snapshot or Download snapshot.
  2. JSON dialog opens — copy all of it. The daily backup status flips to Done.
  3. Teammate: Import snapshot and paste/select the file.

Start the next drop (Drop 002+)

  1. Snapshot first — don't lose Drop 001 history or pics.
  2. Start next drop → name, city wedge, season code.
  3. Hit Open next drop desk.

Other handoff moves

  • Export stage CSV — milestone tracker for spreadsheets.
  • Import stage CSV — refresh gates from a sheet.
  • Investor read — conservative external summary (not raw JSON).
  • Reset Drop 001 demo — back to sample data on this device.

13. Real talk — what works & what doesn't

Works today

  • Any browser — open drop-os.html, no install
  • Saves to this device (localStorage)
  • CSV + JSON handoff between teammates
  • SKU reference photos compressed in-browser
  • All 10 lanes navigate + playbook strips render
  • Bag check, heat logging, tasks, proof links, interactive checklists, snapshots, help, new drop dialog

Not built yet

  • Cloud sync or shared login
  • Server-hosted image CDN
  • Content calendar, role filters, proof file uploads
Drop energy and sell-through vibe are working models — not factory guarantees or investor benchmarks. Pair the investor read with real sample, vendor, and test proof.
